# QA Automation Portfolio

Portfolio projektów z zakresu automatyzacji testów.

## Stack

- Playwright
- TypeScript
- API Testing
- GitHub Actions

## Projekty

### Home Budget
Automatyczne testy aplikacji do zarządzania budżetem domowym.

Zakres:
- testy E2E
- testy formularzy
- testy importu plików
- testy walidacji
- testy API
- testy regresyjne
